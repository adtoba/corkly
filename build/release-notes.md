## Download Corkly

| Your computer | Download |
| --- | --- |
| **Mac** (Apple Silicon or Intel) | `Corkly-<version>-mac-universal.dmg` |
| **Windows 10 / 11** | `Corkly-Setup-<version>.exe` |

### Installing on Mac
1. Open the `.dmg` and drag **Corkly** into **Applications**.
2. Open Corkly. If macOS says it can't verify the developer, open **System Settings → Privacy & Security**, scroll down and click **Open Anyway** (you only do this once).
3. If it says Corkly "is damaged", open Terminal and run `xattr -cr /Applications/Corkly.app`, then open it again.

### Installing on Windows
1. Run `Corkly-Setup-<version>.exe`.
2. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
